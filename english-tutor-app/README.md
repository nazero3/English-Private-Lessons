# English Tutor App (Grades 9 & 12)

Simple no-install web app for private lessons.

## Features

- Grade selector: 9 or 12
- Unit-by-unit visual grammar explanation
- Fill-in exercises with instant scoring
- End-of-lesson quiz for each unit
- Arabic grammar labels for beginner support

## Run

Open `index.html` directly in your browser.

Optional local server:

```bash
cd /home/N_AB/Teaching/english-tutor-app
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Printable Lesson Sheet

Open `printable-lesson-sheet.html` in browser, then click **Print / Save as PDF**.
It is A4-ready and designed for private lessons.
